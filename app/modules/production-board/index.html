Timer stopped

One shared timer per job. It keeps running if you close this page. Stop it to save hours and update automatic labour cost.

Enter cumulative totals for this batch. Blank means not recorded; enter 0 only when confirmed. When Job Costing is enabled, these saved material and labour totals are used there automatically, replacing other entries in the same category. Automatic labour uses actual hours × the selected saved labour rate, rounded to cents. Job rates are frozen until you select a rate again. Manual totals require a reason and remain fixed when hours change. Missing hours or rates leave the automatic total unrecorded. Inventory is not deducted.
